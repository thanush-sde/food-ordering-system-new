# 🍔 Food Ordering System

A full-stack food ordering platform with role-based access for **customers** and **restaurant owners**.

## Tech Stack
**Backend:** Java 21 · Spring Boot 3.5 · Spring Security · Spring Data JPA (Hibernate) · MySQL · JWT · Maven
**Frontend:** React 19 · Vite · React Router · Tailwind CSS v4 · Axios · Context API

## Status
🚧 In active development. Domain model and project scaffolding in place; API and UI coming next.

## Entities so far
`User`, `Role`, `Address`, `Restaurant`, `MenuItem`, `Order`, `OrderItem`, `Review`
